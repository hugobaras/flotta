# Côté chauffeur

Aucune application, aucun mot de passe.

## Le contrôle avant départ
Scannez le QR code de la cabine. Choisissez votre nom, tapez votre code PIN, puis répondez point par point. Un défaut critique bloque le camion : prévenez votre exploitant. Si le réseau est coupé, le contrôle est conservé et envoyé plus tard ; l'écran l'indique.

## Votre tournée
Vous recevez un lien personnel (SMS, email ou via le QR du camion). La tournée s'ouvre quand le contrôle du jour est fait et que le camion n'est pas bloqué.
- La liste des arrêts donne l'adresse, l'heure prévue, le contact et les consignes.
- **Naviguer** ouvre l'application de navigation de votre téléphone vers l'arrêt.
- Pour chaque arrêt : **Arrivé**, puis **Livré** (avec le nom du destinataire, une photo ou une signature si demandé) ou **Impossible** (avec le motif).
- Hors réseau, vos statuts sont gardés sur le téléphone et envoyés au retour du réseau, sans doublon.

Votre position n'est enregistrée qu'avec vos actions (contrôle, arrivée, livraison). En cas de question sur vos données, adressez-vous à votre employeur.
